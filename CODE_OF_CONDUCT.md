# Code of Conduct

## Our standard

We are committed to a welcoming, professional, and technically rigorous community.
Participants are expected to communicate respectfully, focus on technical substance,
and avoid harassment, discrimination, personal attacks, and intentional disruption.

## Security research

Security discussions must remain responsible and authorized. Do not publish credentials,
private tokens, private customer data, or step-by-step exploitation details for real systems
in public issues or pull requests. Use the security reporting process described in `SECURITY.md`.

## Enforcement

Project maintainers may remove or moderate content that violates this code of conduct.
Repeated or serious violations may result in temporary or permanent exclusion from the project.

## Scope

This code of conduct applies to the project's repositories, issues, pull requests,
discussions, and other project-managed spaces.
