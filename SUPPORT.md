# Support

## Community support

For usage questions and reproducible non-sensitive problems, open a GitHub issue with:

- Web Audit Pro version
- Python version
- operating system
- exact command used
- sanitized output or traceback
- a minimal reproduction when possible

Never post credentials, API keys, private scope information, customer data, or exploitable
target details in a public issue. Security-sensitive reports belong in `SECURITY.md`.

## Professional support

Organizations that need help with deployment, CI/CD integration, custom audit rules,
reporting workflows, or internal security automation may use the project as a foundation
for professional services or a hosted offering.
